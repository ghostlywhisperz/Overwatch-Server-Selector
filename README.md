A modern, lightweight GUI application that allows Overwatch 2 players to select their preferred game server region by automatically blocking all other regions using Windows Firewall rules.

✨ Features
🎯 Region Selection - Choose your preferred server region (Americas, Europe, Asia Pacific, or Middle East)

🔒 Smart Blocking - Automatically blocks ALL other regions while keeping your selected region accessible

⚡ One-Click Operation - Simple interface with instant application of firewall rules

💾 Persistent Settings - Your server preference is saved and automatically reapplied on startup

🖥️ Modern UI - Clean, gaming-inspired interface with smooth animations

🚀 Lightweight - Minimal resource usage, no background processes

🛡️ Admin Integration - Automatic elevation request for firewall modifications

📋 Requirements
Windows 10/11 (64-bit)

Overwatch 2 installed

Administrator privileges (for firewall rule management)

🚀 Quick Start
Download the latest release from the Releases page

Run as Administrator (required for firewall access)

Select your preferred server region

Restart Overwatch 2 for changes to take effect

🎯 How It Works
The application creates Windows Firewall rules that block outgoing connections to Overwatch 2 server IP ranges for all regions EXCEPT your selected one. This effectively forces the game to connect only to servers in your chosen region.
